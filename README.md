# SiO

A lightweight graphical utility for Linux to completely and permanently remove program directories.

## Installation

```bash
git clone https://github.com
cd sio-cleaner
sudo chmod +x install.sh
sudo ./install.sh
```

## Uninstallation

```bash
sudo chmod +x uninstall.sh
sudo ./uninstall.sh
```

## Usage

After installation, you can launch **SiO** from your application menu.
